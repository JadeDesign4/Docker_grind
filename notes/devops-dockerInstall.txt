### Step 2: The Grind (45 mins) - Docker Prep
If you haven't run the commands from last night yet, now is the time. We aren't just installing software; we are setting up a **Virtual Environment** that recruiters actually care about.

**Run these one by one:**
```bash
# 1. Install the engine
sudo pacman -S docker

# 2. Start the service
sudo systemctl enable --now docker

# 3. Join the 'docker' group (Crucial so you don't use 'sudo' for every command)
sudo usermod -aG docker $USER
```
